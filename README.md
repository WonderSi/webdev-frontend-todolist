## 🛠️ Технологии

- **Frontend**: HTML5, CSS3, JavaScript, SASS
- **Архитектура**:
```
scss-jquery/
├─ asets/
│ ├─ fonts/
│ ├─ svg/
├─ dist/
│ ├─ css/
├─ js
├─ scss/
│ ├─ base/ 
│ ├─ components/ 
│ ├─ layout/
│ ├─ utils/
│ └─ main.scss
├─ index.html
├─ README.md
└─ .gitignore
```
